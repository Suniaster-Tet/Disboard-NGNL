# Roles y skills

Los roles describen responsabilidades; cada skill da instrucciones reutilizables en `skills/<nombre>/SKILL.md`. La autoridad humana conserva las decisiones de alcance, aprobación y publicación.

| Agente | Responsabilidad | Skill |
|---|---|---|
| Sora | Planificación, hitos y prioridades | [planificacion-sora](../skills/planificacion-sora/SKILL.md) |
| Shiro | Ejecución técnica, código y cálculos | [ejecucion-shiro](../skills/ejecucion-shiro/SKILL.md) |
| Stephanie Dola | Orquestación, integración editorial y entrega | [revision-stephanie](../skills/revision-stephanie/SKILL.md) |
| Fiel Nirvalen | Asistencia administrativa y borradores de correo | [asistencia-fiel](../skills/asistencia-fiel/SKILL.md) |
| Izuna Hatsuse | Ingeniería y validación de datos | [ingenieria-datos-izuna](../skills/ingenieria-datos-izuna/SKILL.md) |
| Jibril | Descubrimiento y síntesis bibliográfica | [bibliografia-jibril](../skills/bibliografia-jibril/SKILL.md) |
| Kurami Zell | Revisión lógica y crítica adversarial | [revision-critica-kurami](../skills/revision-critica-kurami/SKILL.md) |
| Clammy Zell | Alineación con objetivos y restricciones | [alineacion-clammy](../skills/alineacion-clammy/SKILL.md) |

La consola asigna skills según el responsable de cada entregable. El grafo web carga Sora, Shiro y Kurami; incorpora Jibril cuando existen notas bibliográficas locales. La cobertura, convención y límites de cada skill están en [skills/README.md](../skills/README.md); el flujo operativo está en [architecture.md](architecture.md).
